# ESP32-S3 引脚分配表

## GPIO 引脚总览

| GPIO | 功能 | 信号类型 | 配置详情 |
|------|------|----------|----------|
| **3** | SG90 360° 连续旋转舵机 | LEDC PWM ch6 | 50Hz / 11-bit (0-2047) |
| **39** | 步进电机 PUL (脉冲) | AccelStepper 库管理 | DRIVER 模式 |
| **40** | 步进电机 DIR (方向) | AccelStepper 库管理 | DRIVER 模式 |
| **41** | 步进电机 ENA (使能) | 数字输出 | HIGH=禁用, LOW=使能 |
| **42** | SG90 180° 舵机 | LEDC PWM ch5 | 50Hz / 10-bit (0-1023) |
| **47** | 大舵机 (Servo) | LEDC PWM ch7 | 50Hz / 12-bit (0-4095) |
| **8** | 继电器 1 | 数字输出 | LOW=吸合, HIGH=断开 |
| **9** | 继电器 2 | 数字输出 | LOW=吸合, HIGH=断开 |

---

## LEDC PWM 通道

| 通道 | 频率 | 分辨率 | GPIO | 设备 |
|------|------|--------|------|------|
| ch5 | 50Hz | 10-bit | 42 | SG90 180° 舵机 |
| ch6 | 50Hz | 11-bit | 3 | SG90 360° 舵机 |
| ch7 | 50Hz | 12-bit | 47 | 大舵机 |

---

## 步进电机

| 引脚 | 信号 | 说明 |
|------|------|------|
| GPIO39 | PUL | 脉冲信号，控制步数和速度 |
| GPIO40 | DIR | 方向信号，HIGH=正转, LOW=反转 |
| GPIO41 | ENA | 使能信号，LOW=电机使能, HIGH=电机禁用 |

> 使用 AccelStepper 库 DRIVER 模式，最大速度 5000 step/s，加速度 5000 step/s²

---

## 键盘控制

| 按键 | 功能 |
|------|------|
| **A** | 步进电机正转 |
| **D** | 步进电机反转 |
| **S** | 步进电机停止 |
| **W** | 步进电机快速正转 |
| **E** | 步进电机快速反转 |
| **Z** | 大舵机 → 0° |
| **X** | 大舵机 → 90° |
| **C** | 大舵机 → 180° |
| **T** | SG90 360° → 反转 |
| **Y** | SG90 360° → 停止 |
| **U** | SG90 360° → 正转 |
| **Q** | SG90 180° → 0° |
| **R** | SG90 180° → 90° |
| **F** | SG90 180° → 180° |
| **G** | 继电器1 切换 |
| **H** | 继电器2 切换 |
| **1-5** | 运行模式 1-5 |
| **0** | 停止模式 |
